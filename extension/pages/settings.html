插件说明

Image Collector 用于收集、预览和批量下载网页图片。

  • 右键收集单张图片，或解析页面后勾选多张添加。
  • 收集列表支持大图预览、日期分组、批量下载与删除。
  • 数据保存在本地扩展存储，可用 JSON 导入导出备份。
  • 不上传采集记录；预览和下载会访问图片原站。

下载设置说明

  1. 在浏览器地址栏打开 chrome://settings/downloads。
  2. 关闭“下载前询问每个文件的保存位置（Ask where to save each file before downloading）”。
  3. 在本页“下载目录”填写子目录（例如 image-collector）；留空就使用系统默认下载目录。
  4. 打开 chrome://extensions/，点击本插件“重新加载”后再测试下载。
